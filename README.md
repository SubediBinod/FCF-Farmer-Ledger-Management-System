# First Choice Foods Limited Farmer Ledger Management System

A financial and agricultural CRM system designed to manage farmer groups, cultivation tracking, crop procurement, and ledger-based payment settlements.

---

## 🚀 Overview

This system manages:

* Farmer registration and profiles
* Group-based farmer organization
* Cultivation tracking
* Seed and potato ledger calculations
* Payment and balance management

---

## 🏗️ Architecture

* React + Tailwind CSS
* Spring Boot REST APIs
* MySQL
* JWT Authentication

---

## 👨‍🌾 Core Features

### Farmer Management

* Farmer registration with ID system
* Bank and identity details
* Group-based organization
* Photo capture/upload

### Group System

* Province & district grouping
* Farmer cluster management

### Ledger System

* Seed cost tracking
* Potato procurement valuation
* Grade-based pricing system
* Balance calculation engine

### Payment System

* Payment logging
* Batch payments
* Ledger history tracking

---

## 🧮 Business Logic Example

* Seed cost calculation
* Potato grade valuation (A/B/Other)
* Remaining balance computation

---

## 📊 Impact

* Digitized farmer procurement tracking
* Improved financial transparency
* Reduced manual ledger errors
